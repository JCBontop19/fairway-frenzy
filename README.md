Fairway Frenzy

A golf-themed 2D bullet hell, built solo in Godot for my Game Development/Interface course. Fight through waves of enemies that shoot projectiles and charge at you, grab power-ups, and take down the final boss.

Engine: Godot (GDScript) · Status: Completed course project (solo)

*I need to add a gameplay screenshot*

Gameplay
Move freely around the arena and attack enemies as they come at you
Enemies either fire projectile patterns or charge the player directly
Clear every wave, then defeat the final boss to win
Take too much damage and the run is over

Technical highlights
Bullet patterns: enemy projectile patterns that give each enemy type its own attack and threat
Wave system: structured enemy waves that ramp up difficulty and lead into the boss fight
Power-ups: collectible pickups that temporarily change the player's abilities

Running the project
Install Godot 4.
Clone this repo and open project.godot in Godot.
Press F5 to run.

Controls
Move | WASD
Attack | Space
Pause | Esc
